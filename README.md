# Disrupção 2027 · Concurso IGPREV

Landing page do I Concurso de Artigos Científicos IGPREV.

## Estrutura

- `index.html`: página completa (CSS e imagens embutidos, um único arquivo)

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `disrupcao-2027`).
2. Envie os arquivos deste projeto para a branch `main`.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. Salve. Em alguns minutos o site estará em `https://SEU-USUARIO.github.io/disrupcao-2027/`.

## Editar

Abra o `index.html` em qualquer editor de texto. Textos, links e cores estão no próprio arquivo, na seção `<style>` e no corpo da página.

Links de download (edital, ficha) estão marcados com `href="#"`: troque pelos caminhos dos arquivos ou pelas URLs reais.
